# Research 0.97 — explicit legacy profile facts

The original 172 biographies, frozen assessment answers, split identities and 1,828 existing typed profiles are unchanged. `legacy-facts.json` is a separate manually reviewed overlay, created before viewing 0.97 matching outcomes. Each simulator predicate cites an exact original quotation and source path, with the original case-file SHA-256. All current-life enjoyed/avoided observations are retained for inspection; only the explicitly mapped facts drive simulated answers. No keyword classifier runs over student text. No demographics, educational aspirations, desired matching outcomes, demonstrated ability alone or lack of exposure supplies an interest. Context-specific avoidances are preserved but never generalized into rejection of a whole broader topic or method. A source-scoped guard also separates historical/argument writing from a creative-writing specialty; explicit creative work is required for that specialty. Unstated interests, professional responsibility and specialties remain unknown. A reviewed profile can therefore be evaluable and still have no supported Top.

`profiles.mjs` validates frozen source hashes and creates typed preferences. `answer.mjs` retains the unchanged 0.96 resolver but replaces synthetic-template evidence with actual source quotations for legacy profiles. All 2,000 runs start with fresh state, copying only lifestyle and the official 60 profiler responses. No prior field/profession answers are copied. Budgets are 0, 4, 8, 12, 16, 24, 36 and 60 extra items; unknown costs one question. The unchanged deterministic order may be reused only when every recomputed answer and evidence reference is identical; every checkpoint is freshly scored and checked against the canonical matching engine. Any changed answer triggers complete adaptive selection. This preserves fresh-start semantics without replaying identical adaptive branches needlessly.

0.96 is the immutable comparator. Development, original holdout, fresh holdout and expansion holdout remain distinct. These splits have previously been inspected and should not be described as unseen validation. The Grok cohort is reported separately; its underlying profiles, responses and matching decisions must remain identical. This is synthetic procedural evaluation, not evidence of student outcomes or independent psychometric validation. The live flow and matching policy are unchanged.

Reproduction: `python3 scripts/shared-foundation.py run -- node scripts/prepare-evidence-097.mjs`. For a fully adaptive pilot: `LIMIT097=14 NO_TRACE097=1 python3 scripts/shared-foundation.py run -- node scripts/rerun-evidence-097.mjs` (writes pilot directory). The public payload is a lossless patch over immutable 0.96, itself a patch over 0.95. Public chart defaults to reviewed/evaluable models; missing career-specific evidence is shown as “No supported Top yet”, not “Not evaluable”.
